# Chapter 5: Dictionaries and Sets

This chapter covers two more collection types: **dictionaries** (key-value pairs) and **sets** (unique items).

## Dictionary vs Set

| Feature | `dict` | `set` |
| ------- | ------ | ----- |
| Example | `{"a": 1}` | `{1, 2, 3}` |
| Stores | Key-value pairs | Single unique items |
| Mutable | Yes | Yes |
| Duplicates | Keys: no, values: yes | No |
| Access by | Key | Cannot index |
| Empty version | `{}` | `set()` |

## Summary

* Use a **dictionary** to look up a value by its key.
* Use a **set** to store unique items and remove duplicates.
