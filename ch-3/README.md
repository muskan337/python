## Quick Revision

| Idea | Example |
| ---- | ------- |
| Create | `"hello"` or `'hello'` |
| Length | `len("hello")` gives `5` |
| Index | `"hello"[1]` gives `'e'` |
| Slice | `"hello"[1:4]` gives `'ell'` |
| Immutable | `s[0] = "H"` gives `TypeError` |
| Methods | `.upper()`, `.lower()`, `.replace()`, `.find()` |
